WHAT I LEARNED(TIPS AND BOTTLENECKS)

(TIP/BOTTLENECK)Because I was allowed to use AI to help me complete this assignment, I used it whenever and wherever possible. However, while this helped a lot, I quickly recognized that it can't do everything, and sometimes it's a little overconfident in its abilities.

 (TIP) I found that I often asked Claude to troubleshoot code for me, and while it would do that, it would often go one step too far, which meant I had to backtrack and end up fixing code that worked in the first place.
 
 (TIP) I also learned to take things one step at a time. Seeing all these files and all the code was overwhelming at first because I looked at it as a whole instead of in chunks. Once I got into a rhythm and took things one at a time, everything became much more manageable.
 
 (BOTTLENECK) Another Bottleneck I faced was the different system I was using. I learned how to use some of VS Code on Windows, but for this project I had to switch to Mac, which was a decent learning curve, as while most things are very similar, some things are very different.
